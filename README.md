## ১. পরিচিতি ও ওভারভিউ

**ভাগ্য উন্নয়ন সমাজ কল্যাণ সংস্থা** প্রান্তিক জনগোষ্ঠীর আত্মসামাজিক উন্নয়ন, ক্ষুদ্র সঞ্চয় বৃদ্ধি ও মানবকল্যাণে নিবেদিত একটি আধুনিক ও পূর্ণাঙ্গ সমবায় ব্যবস্থাপনা প্ল্যাটফর্ম। এই সফটওয়্যারটি উচ্চস্তরের আর্থিক নিরাপত্তা, ডাবল-এন্ট্রি লেজার আর্কিটেকচার, সিইও অনুমোদন প্রক্রিয়া এবং সম্পূর্ণ বাংলা ইন্টারফেসের ওপর ভিত্তি করে তৈরি করা হয়েছে।

## ২. প্রযুক্তিগত স্ট্যাক (Technology Stack)

- **ফ্রেমওয়ার্ক:** [Next.js](https://nextjs.org/) (App Router, React Server & Client Components)
- **প্রোগ্রামিং ভাষা:** TypeScript (Strict Mode)
- **স্টাইলিং:** Tailwind CSS (কাস্টম ব্র্যান্ড প্যালেট: বনসবুজ, নেভি ব্লু ও গোল্ডেন অরেঞ্জ)
- **টাইপোগ্রাফি:** Hind Siliguri (Google Fonts)
- **আইকন:** Lucide React
- **ডাটাবেস ও স্টোরেজ:** Firebase Cloud Firestore & Firebase Storage
- **অথেনটিকেশন:** Firebase Authentication ও রোল-বেসড সেশন সিকিউরিটি
- **সার্ভার লজিক:** Next.js Route Handlers & Firebase Admin SDK
- **ভ্যালিডেশন:** Zod, React Hook Form
- **আর্থিক হিসাব:** Integer Poisha (১ টাকা = ১০০ পয়সা)

## ৪. আর্থিক লেজার ও ব্যাংকিং-স্টাইল নিরাপত্তা নীতি

1. **ইনটিজার পয়সা স্টোরেজ:** ফ্লোটিং পয়েন্ট ত্রুটি প্রতিরোধে সকল আর্থিক হিসাব ইনটিজার পয়সা (Integer Poisha) হিসেবে সংরক্ষিত (যেমন: ৫০০.০০ টাকা = ৫০০০০ পয়সা)।
2. **দ্বৈত অনুমোদন প্রক্রিয়া:** মাঠকর্মীরা অর্থ কালেকশন এন্ট্রি দাখিল করলে তা `PENDING` অবস্থায় থাকে। সিইও মহোদয়ের অনুমোদন ছাড়া সদস্যের কার্যকরী ব্যালেন্সে কোনো অর্থ যুক্ত হয় না।
3. **আত্ম-অনুমোদন নিষেধাজ্ঞা:** কর্মীরা নিজেদের দাখিলকৃত এন্ট্রি নিজেরা অনুমোদন করতে পারেন না এবং সরাসরি কোনো সদস্যের ব্যালেন্স সম্পাদন করতে পারেন না।
4. **উত্তোলন সুরক্ষা:** সদস্যের জমাকৃত কার্যকরী ব্যালেন্সের অতিরিক্ত অর্থ উত্তোলনের আবেদন স্বয়ংক্রিয়ভাবে সিস্টেম কর্তৃক বাতিল হয়।
5. **অপরিবর্তনীয় লেজার:** অনুমোদিত লেনদেনের বিপরীতে স্বয়ংক্রিয়ভাবে অপরিবর্তনীয় অডিট লগ ও লেজার এন্ট্রি তৈরি হয়। কোনো তথ্য মুছে ফেলা যায় না।

## ৬. লোকাল সেটআপ ও ডিপ্লয়মেন্ট গাইড

### ১. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ২. এনভায়রনমেন্ট ভেরিয়েবল সেটআপ
প্রকল্পের মূল ডিরেক্টরিতে `.env.example` ফাইলের অনুকরণে `.env.local` তৈরি করুন:
```bash
cp .env.example .env.local
```
ফায়ারবেস কনসোলে প্রজেক্ট তৈরি করে ক্রেডেনশিয়ালসমূহ বসান:
- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY`
- `ADMIN_SETUP_TOKEN`

### ৩. অটোমেটেড টেস্ট চালান


## ৮. ভার্সেল (Vercel) ডিপ্লয়মেন্ট

1. প্রকল্পটি GitHub বা GitLab রিপোজিটরিতে পুশ করুন।
2. [Vercel](https://vercel.com/) ড্যাশবোর্ডে গিয়ে নতুন প্রজেক্ট হিসেবে ইমপোর্ট করুন।
3. **Environment Variables** সেকশনে `.env.example` ফাইলের ভেরিয়েবলগুলো যুক্ত করুন।
4. **Deploy** বাটনে ক্লিক করুন। Vercel স্বয়ংক্রিয়ভাবে Next.js App Router বিল্ড সম্পন্ন করবে।

## ৯. প্রগ্রেসিভ ওয়েব অ্যাপ (PWA) ও মোবাইল ইনস্টলেশন গাইড

সিস্টেমটি সম্পূর্ণ ইনস্টলেবল প্রগ্রেসিভ ওয়েব অ্যাপ (PWA) হিসেবে রূপান্তরিত:

### ক. PWA আর্কিটেকচার ও উপাদানসমূহ
- **Web App Manifest (`src/app/manifest.ts`):** 
  - Application Name: `Bhagya Unnayan Samaj Kallyan Sangstha`
  - Short Name: `Bhagya Society`
  - Theme Color: `#0f5132` (বনসবুজ)
  - Background Color: `#f8fafc`
  - Display: `standalone` (ব্রাউজার বার ছাড়া ফুলস্ক্রিন অ্যাপ মোডে চলে)
  - Icons: সংস্থার লোগো থেকে তৈরিকৃত ১৯২x১৯২ এবং ৫১২x৫১২ পিএনজি আইকন (সহ মাস্কেবল আইকন ও অ্যাপল টাচ আইকন)।
- **সার্ভিস ওয়ার্কার (`public/sw.js`):**
  - স্ট্যাটিক অ্যাসেট ক্যাশিং (HTML Shell, Icons, CSS, JS)।
  - **আর্থিক নিরাপত্তা আইসোলেশন:** `/api/*`, `/ceo/*`, `/employee/*`, `/maintenance/*` রাউটগুলো কখনই ব্রাউজার ক্যাশে জমা রাখা হয় না।
  - **অফলাইন নিরাপত্তা:** ইন্টারনেট সংযোগ বিচ্ছিন্ন হলে অফলাইন ফলব্যাক পেজ (`/offline`) প্রদর্শিত হয়। কোনো আর্থিক লেনদেন বা অনুমোদন অফলাইনে জমা হয় না।

### খ. বিভিন্ন ডিভাইসে ইনস্টলেশন প্রক্রিয়া
1. **Android (Google Chrome / Brave / Edge):**
   - ওয়েবসাইটে প্রবেশ করলে হোমপেজের **"অ্যাপ ইনস্টল করুন (PWA)"** বোতাম চাপুন।
   - ব্রাউজারের নেটিভ ইনস্টলেশন প্রম্পট প্রদর্শিত হবে। **Install** নির্বাচন করলেই অ্যাপটি হোমস্ক্রিন ও অ্যাপ ড্রয়ারে ইনস্টল হবে।
2. **iPhone ও iPad (Apple Safari):**
   - ওয়েবসাইটে প্রবেশ করে **"অ্যাপ ইনস্টল করুন"** চাপলে ধাপে ধাপে নির্দেশনা পপ-আপ আসবে।
   - সাফারি ব্রাউজারের নিচের দিকে **শেয়ার (Share) বাটন 📤** ট্যাপ করুন।
   - নিচে স্ক্রল করে **"Add to Home Screen" (হোম স্ক্রিনে যোগ করুন ➕)** চাপুন এবং উপরে **"Add"** চাপুন।
3. **Desktop (Windows/Mac Chrome বা Edge):**
   - ব্রাউজার এড্রেস বারের ডানপাশে ইনস্টল আইকন (⊕) প্রদর্শিত হবে অথবা হোমপেজের ইনস্টল বাটনে ক্লিক করে ডেস্কটপ অ্যাপ হিসেবে ইনস্টল করা যাবে।
